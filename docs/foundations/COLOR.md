# STRATA Color

STRATA is monochrome first.

## Monochrome

Black, white and gray establish structure, hierarchy and reading order.

## Spectrum

The only seven color families are:

- Red — error / critical
- Orange — warning / attention
- Yellow — caution / pending
- Green — success / confirmed
- Blue — information / links
- Indigo — context / secondary emphasis
- Violet — special / exceptional category

**Monochrome establishes structure. Color establishes meaning.**

Spectrum color is deliberately sparse. If a screen remains coherent when spectrum color is removed, it is behaving correctly.
